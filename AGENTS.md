# Repository hosting

- The canonical repository is https://github.com/Jiangys-Crz/xcpc-oj-contest-helper.
- Push future changes and open pull requests on GitHub. Keep `origin` and the default push target on GitHub.
- The Gitee repository has been deleted. Use GitHub only for repository fetches, pushes, and pull requests.
- Client updates download published, checksum-verified packages from https://vp.cwnupaa.com by default. Use GitHub `main` only with explicit `xcpc update --github`; do not silently fall back to GitHub. Publish server packages from commits already pushed to GitHub.
