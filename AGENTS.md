# Repository hosting

- The canonical repository is https://github.com/Zyihan-Crz/xcpc-oj-contest-helper.
- Push future changes and open pull requests on GitHub. Keep `origin` and the default push target on GitHub.
- Gitee is a historical archive. Do not push new commits there unless the user explicitly requests it.
- Client updates use GitHub `main` by default. The public download manifest remains a compatibility path for older clients and installers.
