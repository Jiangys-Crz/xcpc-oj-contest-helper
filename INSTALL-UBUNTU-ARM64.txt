XCPC 0.8.2 · Ubuntu ARM64 快速安装

完整安装与使用教程请阅读同目录的 README.md。
Ubuntu 24.04 / 26.04 ARM64 使用系统 Python 3.12+；仓库带有适配
Ubuntu 26.04、Python 3.14 ARM64 的依赖 wheels。

1. 将整个源码目录复制到 Ubuntu，或解压源码包后进入 VP 目录。

2. 使用日常 Linux 用户运行：

   bash install.sh --local --offline
   export PATH="$PWD/bin:$PATH"
   xcpc --help

   安装器会自动补齐 Python、venv、Git、tmux 和证书，缺少系统包时
   自动请求 sudo 权限。--offline 只禁止从 PyPI 下载 Python 依赖；
   apt 安装系统包仍可能需要网络。其他 Python 版本缺少对应 wheel 时，
   去掉 --offline 后重试。不要在比赛命令前加 sudo。

   程序保存在 .vp-install，命令在 bin。安装器自动配置 Bash / Zsh
   的命令路径，新终端可直接运行 xcpc；当前终端先执行上面的 export。
   本地安装后不要移动程序目录，移动后需要重新安装。

3. 在同一系统用户的普通 Firefox 窗口登录比赛网站，无需退出浏览器。
   Ubuntu 继续直接读取 Firefox 登录，不使用 Chrome / Edge 扩展。

   xcpc doctor cf
   xcpc doctor qoj
   xcpc doctor paa
   xcpc doctor nk

4. 设置比赛保存目录和 Codeforces API：

   xcpc path
   xcpc api cf

   API 设置页：https://codeforces.com/settings/api
   CF/Gym 的 VP、BT、live 共用配置，用户名不区分大小写。

5. 常用命令：

   vp cf 2181
   vp qoj 3617
   vp gym 100123
   live cf 2277
   live paa 比赛ID
   live nk 比赛ID
   bt 比赛链接

   在原比赛文件夹运行 xcpc dashboard 恢复面板，运行 xcpc end
   结束本地 VP。代码和历史保留，比赛结束后可继续补题。
   同一比赛再次输入命令恢复已有会话，不重新开始 VP。

6. 更新：

   xcpc update

   沿用原安装位置，保留账号、保存路径、代码和比赛历史。
   macOS / Windows 的安装和浏览器扩展步骤请阅读 README.md。
